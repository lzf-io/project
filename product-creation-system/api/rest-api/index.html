    REST API 文档¶

    API 概览¶

    Base URL: https://api.example.com/v1

    所有 API 需要在请求头中携带认证 Token： 

    Authorization: Bearer {access_token}

    1. 产品管理 API¶

    1.1 创建产品¶

    POST /api/products
Content-Type: application/json

{
  "type": "physical",          // physical | digital
  "name": "产品名称",
  "description": "产品描述",
  "category_id": 101,
  "price": 99.00,
  "images": [
    "https://cdn.example.com/image1.jpg"
  ],
  "metadata": {
    "brand": "品牌名",
    "model": "型号"
  }
}

    响应： 

    {
  "code": 0,
  "message": "success",
  "data": {
    "id": 123456,
    "type": "physical",
    "name": "产品名称",
    "status": "active",
    "created_at": "2026-03-12T10:00:00Z"
  }
}

    1.2 查询产品列表¶

    GET /api/products?page=1&size=20&type=digital&status=active

    响应： 

    {
  "code": 0,
  "data": {
    "items": [
      {
        "id": 123456,
        "name": "产品名称",
        "type": "digital",
        "price": 99.00,
        "thumbnail": "https://cdn.example.com/thumb.jpg"
      }
    ],
    "total": 100,
    "page": 1,
    "size": 20
  }
}

    1.3 查询产品详情¶

    GET /api/products/{product_id}

    1.4 更新产品¶

    PUT /api/products/{product_id}
Content-Type: application/json

{
  "name": "新产品名称",
  "price": 149.00
}

    1.5 删除产品¶

    DELETE /api/products/{product_id}

    2. AI 生成 API¶

    2.1 文生图¶

    POST /api/generate/text-to-image
Content-Type: application/json

{
  "prompt": "一只可爱的小猫在花园里玩耍，阳光明媚，高清写实风格",
  "quantity": 4,
  "options": {
    "width": 1024,
    "height": 1024,
    "style": "realistic",      // realistic | anime | abstract
    "negative_prompt": "模糊，低质量"
  }
}

    响应： 

    {
  "code": 0,
  "data": {
    "task_id": "task_abc123xyz",
    "status": "pending",
    "estimated_time": 60,
    "credits_locked": 40
  }
}

    2.2 图生图¶

    POST /api/generate/image-to-image
Content-Type: application/json

{
  "source_image_url": "https://cdn.example.com/source.jpg",
  "prompt": "转换为水彩画风格",
  "quantity": 1,
  "options": {
    "strength": 0.75,          // 0.0 - 1.0
    "style": "watercolor"
  }
}

    响应： 

    {
  "code": 0,
  "data": {
    "task_id": "task_def456uvw",
    "status": "pending"
  }
}

    2.3 AI 增强¶

    POST /api/generate/enhance
Content-Type: application/json

{
  "image_url": "https://cdn.example.com/original.jpg",
  "enhancement_type": "upscale",  // upscale | denoise | colorize
  "options": {
    "scale_factor": 2            // 2x | 4x
  }
}

    响应：

  "data": {
    "task_id": "task_abc123xyz",
    "status": "completed",        // pending | processing | completed | failed
    "progress": 100,
    "results": [
      {
        "image_url": "https://cdn.example.com/result1.jpg",
        "thumbnail_url": "https://cdn.example.com/result1_thumb.jpg"
      },
      {
        "image_url": "https://cdn.example.com/result2.jpg",
        "thumbnail_url": "https://cdn.example.com/result2_thumb.jpg"
      }
    ],
    "credits_used": 40,
    "created_at": "2026-03-12T10:00:00Z",
    "completed_at": "2026-03-12T10:01:23Z"
  }
}

    2.5 取消生成任务¶

    POST /api/generate/tasks/{task_id}/cancel

    响应： 

    {
  "code": 0,
  "message": "任务已取消，积分已退回"
}

    3. 积分管理 API¶

    3.1 查询积分余额¶

    GET /api/credits/balance

    响应： 

    {
  "code": 0,
  "data": {
    "balance": 500,
    "locked": 40,
    "available": 460,
    "level": "premium",
    "updated_at": "2026-03-12T10:00:00Z"
  }
}

    3.2 查询积分交易记录¶

    GET /api/credits/transactions?page=1&size=20&type=deduct

    参数： - type: lock | deduct | unfreeze | recharge

    响应： 

    {
  "code": 0,
  "data": {
    "items": [
      {
        "id": 789,
        "type": "deduct",
        "amount": -40,
        "balance_after": 460,
        "description": "文生图生成消耗",
        "task_id": "task_abc123xyz",
        "created_at": "2026-03-12T10:01:23Z"
      }
    ],
    "total": 50,
    "page": 1
  }
}

    3.3 充值积分¶

    POST /api/credits/recharge
Content-Type: application/json

{
  "package_id": "pkg_100",      // 套餐 ID
  "payment_method": "alipay"    // alipay | wechat | stripe
}

    响应： 

    {
  "code": 0,
  "data": {
    "order_id": "order_xyz789",
    "payment_url": "https://pay.example.com/order_xyz789",
    "amount": 99.00,
    "credits": 1000
  }
}

    错误码说明¶

    Code 说明 处理建议
    0 成功 -
    40001 参数错误 检查请求参数
    40002 认证失败 重新登录
    40003 权限不足 升级会员等级
    40004 资源不存在 检查资源 ID
    40005 配额不足 等待重置或升级
    40006 积分不足 充值积分
    40007 生成任务失败 重试或联系客服
    50001 服务器错误 稍后重试
    50002 AI 服务不可用 稍后重试
    50003 数据库错误 联系客服

    WebSocket 实时通知¶

    连接地址: wss://api.example.com/v1/ws?token={access_token}

    生成进度通知¶

    {
  "type": "generation_progress",
  "task_id": "task_abc123xyz",
  "progress": 50,
  "status": "processing",
  "message": "正在生成第2张图片..."
}

    生成完成通知¶

    {
  "type": "generation_completed",
  "task_id": "task_abc123xyz",
  "results": [
    {
      "image_url": "https://cdn.example.com/result1.jpg"
    }
  ]
}

    积分变动通知¶

    {
  "type": "credits_changed",
  "balance": 460,
  "locked": 0,
  "change_amount": -40,
  "reason": "生成任务消耗"
}

    请求限流¶

    API 类型 限流规则
    查询类 API 100次/分钟/用户
    生成类 API 10次/分钟/用户
    充值/升级 API 5次/分钟/用户

    超过限流返回： 

    {
  "code": 42901,
  "message": "请求过于频繁，请稍后再试",
  "retry_after": 60
}
